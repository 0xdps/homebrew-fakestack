# homebrew-packages

Homebrew tap for [fakestack](https://github.com/0xdps/fake-stack) - a high-performance database generator with realistic fake data.

## Installation

```bash
brew tap 0xdps/packages
brew install fakestack
```

## About

fakestack is a high-performance database generator that creates realistic fake data. This Homebrew tap provides easy installation and updates for macOS and Linux systems.

### Supported Platforms

- macOS (Apple Silicon and Intel)
- Linux (ARM64 and AMD64)

## Usage

After installation, you can use the `fakestack` command:

```bash
fakestack -d .
```
